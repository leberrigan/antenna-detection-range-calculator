Reading this chart

  • Same modelling approach as the VHF Nanotag tool, adapted for a 2.4 GHz BLE beacon tag: free-space path loss, an NEC2-simulated ground antenna pattern per terrain, and a per-terrain ground-roughness floor of −15 dB on the receive antenna's modelled gain.
  • The receive antenna is an 11-element 2450 MHz Yagi (WA5VJB “Cheap Yagi,” a real published Kent Britain design), vertically polarized, at 6 m AGL — simulated fresh in NEC2 for this tool.
  • Range envelope is altitude-limited even more sharply than the 434 MHz tool. This Yagi's usable elevation lobes are concentrated below roughly 10°, and 2.4 GHz path loss is steep, so quiet/typical/noisy range collapses toward a small near-overhead value above roughly 300–600 m AGL. Treat this tool as a ground-level / low-altitude range model — it is not well suited to high-flying tags.
  • The chart and heatmaps are scaled to this system's own useful envelope (a few km, under ~500 m AGL) rather than the VHF tool's 130 km/3000 m axes.
  • Tag output is modelled as 0.0 dBm conducted (1 mW, typical BLE Class 2/nRF52‑class radio) + −3.0 dBi antenna ≈ −3.0 dBm EIRP — these are assumption-driven parameters (no single published BLE wildlife tag spec was available to anchor them to), chosen to be representative of a compact PCB/chip-antenna BLE beacon tag rather than any specific product.
  • Receiver sensitivity scenarios use the same AGC-reference formula as the other two tools, evaluated at BLE's much wider ~2 MHz channel bandwidth, with an 8 dB / 15 dB quiet→noisy spread.
  • No vegetation canopy loss, body-shadowing, Bluetooth channel-hopping/coding-scheme gain (e.g. BLE Long Range / Coded PHY), or multipath fading beyond the ground-roughness floor is modelled. A tag using Coded PHY would out-range this model; one using standard 1M PHY advertising will roughly match it.
Link budget: Prx(dBm) = 0.0 + (−3.0) − FSPL(2440 MHz, d) + Grx(terrain, elevation), floored at −15 dB. FSPL(dB) = 32.44 + 20·log₁₀(fMHz) + 20·log₁₀(dkm), horizontal distance only. Sensitivity thresholds: −174 + NF + SNR + 10·log₁₀(2·BW) + fade margin. Radio horizon: 4.12·(√hant + √htag) km. Elevation-gain patterns computed in NEC2 (nec2++/PyNEC), 1° resolution, 6 ground types.
